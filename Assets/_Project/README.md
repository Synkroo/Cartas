# Project Folder Layout

This folder contains the playable project assets, grouped by intent:

- `Animation`: animation clips and animator controllers.
- `Art`: sprites and visual source assets.
- `Code`: runtime scripts and editor-only tooling.
- `Data`: ScriptableObjects and game content definitions.
- `Documentation`: reference screenshots and project notes.
- `Prefabs`: reusable scene and UI prefabs.
- `Resources`: assets loaded through `Resources.Load`.
- `Scenes`: Unity scenes included in build settings.
- `Settings`: render pipeline, input, TextMesh Pro, and project asset settings.
- `Tests`: edit mode and play mode test assemblies.
- `Archive`: recovery or deprecated assets kept for reference.
